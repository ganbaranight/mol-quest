function generate(){ const pairs= level===1? ['mn','nm']: level===2? ['pn','np','vn','nv']: level===3? ['mp','pm','mv','vm','pv','vp']: ['ma','na','pa','va','mn','nm', 'mp','pm','mv','vm']; const pair=pick(pairs); const [from,to]=pair; const pool=substances.filter(s=> (!pair.includes('v')||s[3])&& (!pair.includes('a')||s[4]>0)&& (level!==1||!s[2].includes('(')) ); const [ name, formula, molarExpr, gas, atomCount, atomName, particleType ]=pick(pool); const particle= particleType==='式単位'? '組成式で表される粒子': particleType; const M=parseMath(molarExpr).value; const n=pick([ .1,.2,.25,.3,.5,.75, 1,1.2,1.5,2,2.5,3,4 ]); const vals={ m:clean(n*M), n:n, p:clean(n*NA), v:clean(n*VM), a:clean(n*NA*(atomCount||1)) }; const units={ m:'g', n:'mol', p:'個', v:'L', a:'個' }; const labels={ m:'質量', n:'物質量', p:'粒子数', v:'気体の体積', a:'原子数' }; const start=sci(vals[from]); const factors={ m:`(${molarExpr})`, p:'6.0E23', v:'22.4' }; const numericFactors={ m:M, p:NA, v:VM }; let model=start; const expected=[ {value:vals[from],sign:1} ]; if(from!=='n'){ model+='/'+factors[from]; expected.push({ value:numericFactors[from], sign:-1 }); } if(to==='a'){ model+='*6.0E23*'+atomCount; expected.push({ value:NA, sign:1 }); expected.push({ value:atomCount, sign:1 }); }else if(to!=='n'){ model+='*'+factors[to]; expected.push({ value:numericFactors[to], sign:1 }); } // ================================== // 問題文の生成 // ================================== const substance=`${name} ${formula}`; const amount=pretty(start); let subject=''; if(from==='m'){ subject=`${substance} ${amount} g`; } if(from==='n'){ subject=`${substance} ${amount} mol`; } if(from==='p'){ subject= `${substance} の${particle} ${amount} 個`; } if(from==='v'){ subject= `標準状態における ${substance} ${amount} L`; } let text=''; if(to==='m'){ text=`${subject} の質量は何 g か。`; } if(to==='n'){ text=`${subject} の物質量は何 mol か。`; } if(to==='v'){ text= `${subject} の標準状態における体積は何 L か。`; } if(to==='p'){ text= `${subject} に含まれる${particle}は何個か。`; } if(to==='a'){ text= `${subject} に含まれる${atomName}原子は何個か。`; } // ================================== // ヒント // ================================== const toMolHints={ m:'質量をモル質量で割る。', p:'粒子数をアボガドロ定数で割る。', v:'気体の体積を22.4で割る。', n:'与えられた物質量を使う。' }; const fromMolHints={ m:'物質量にモル質量を掛ける。', p:'物質量にアボガドロ定数を掛ける。', v:'物質量に22.4を掛ける。', n:'', a:`分子数を求め、1分子中の${atomName}原子の数を掛ける。` }; let hint= toMolHints[from]+' '+fromMolHints[to]; if(pair.includes('m')){ hint+=' モル質量は原子量から求めよう。'; } if(to==='a'){ hint+= ` 1分子中の${atomName}原子は${atomCount}個。`; } // ================================== // 解説・模範解答 // ================================== const explain= (pair.includes('m')? `モル質量：${pretty(molarExpr)} = ${M} g/mol。 `: '')+ `物質量は ${n} mol。 `+ `${pretty(model)} = ${formatNumber(vals[to])} ${units[to]}`; return { category:labels[from]+' → '+labels[to], text:text, unit:units[to], answer:vals[to], modelExpr:model, molarExpr:molarExpr, expected:expected, from:from, to:to, hint:hint, explain:explain, model: `${pretty(model)} = `+ `${formatNumber(vals[to])} ${units[to]}` }; }
